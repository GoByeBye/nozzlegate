# Page Markdown

The homepage, reporting guide, contribution guide, and privacy notice keep their editorial copy
in this directory. YAML front matter provides structured text to the existing
page layouts:

- `home.md`
- `report.md`
- `contribute.md`
- `privacy.md`

Application components define presentation and accessible interaction. They
should not contain factual claims, reporting instructions, evidence policy, or
other editorial prose that belongs here.
