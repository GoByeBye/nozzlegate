# Project notices

## AI-assisted work

AI tools have helped with parts of the code, design, research organization,
tests, and first drafts for this project. Human maintainers decide what is
published, verify claims against the cited records, review the resulting code
and prose, and remain responsible for the site.

AI output is never treated as a source or independent verification. Evidence
must still trace back to an original record that a person can check.

Credentials identifying it as AI-generated media.
