# Evidence submissions

Do not place unredacted customer documents in this repository.

For a public evidence copy:

1. preserve the original separately;
2. redact card numbers, addresses, phone numbers, signatures, account IDs,
   support tokens, unrelated order data, and community usernames that are not
   necessary to understand the evidence;
3. leave the seller, date, product, currency, payment method, disputed line
   item, and total visible when they are relevant;
4. use a descriptive filename such as
   `2026-03-20-bondtech-card-fee-redacted.pdf`; and
5. add provenance and a plain-language description in the pull request.

An image or PDF in this folder is not automatically licensed by the project.
State whether the contributor owns it and what reuse, if any, is permitted.

For chat records, use stable neutral labels such as `Community member 1` so a
conversation remains understandable without publishing participant handles.
Retain a name only when it is materially necessary to attribute an official
company statement, and document why.
